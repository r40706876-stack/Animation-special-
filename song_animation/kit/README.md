# Song Kit Film — gaana daalo, video pao

1. GitHub par `song_animation/inputs/` kholo → **Add file → Upload files** → gaana (mp3/m4a) daalo → **Commit**.
2. "Song Kit Film (automatic)" workflow apne aap chalega (Actions tab).
3. 10–20 minute me run ke summary me ✅ ke saath video ka link aayega (Releases me bhi milega).
4. Gemini ka quota us din khatam ho to wo gaana roz 13:50 IST par apne aap dobara try hota hai.

Kaise banta hai: gaane ka sabse jordaar 30 s hissa chuna jata hai → Gemini Hindi bol + timing nikalta hai →
Gemini har line ke liye kit (aasmaan, zameen, kamra, 40+ cheezein, log, effects) se naya scene jodta hai →
code saare chitra banata hai (koi image service/quota nahi) → bol + audio ke saath video.
Gemini na mile to bol ke shabdon se scene chune jaate hain; bol pakke na hon to captions nahi lagte.
